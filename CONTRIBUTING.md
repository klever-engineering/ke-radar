# Contributing to KE Radar

Thanks for helping improve KE Radar. This repo is focused on structured technology evaluation.

## How to Contribute
- Propose a new technology pilot in `ROADMAP.md`.
- Add or improve templates in `templates/`.
- Share pilot results in `pilots/<technology>/`.

## Workflow
1. Create a branch: `radar-<technology>` or `docs-<topic>`.
2. Update or add the relevant files.
3. Open a pull request with a clear summary.

## Standards
- Follow the runbook: `RUNBOOK.md`.
- Use the pilot templates as the source of truth.
- Keep changes scoped and auditable.

## Code of Conduct
By participating, you agree to the Code of Conduct in `CODE_OF_CONDUCT.md`.
